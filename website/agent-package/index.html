05 / KNOW THE LIMITS

Useful evidence.
Visible uncertainty.

Local models
TransNet, SAM 2.1 and SAM 3.1 have explicit model packs. The MLX route is specific to Apple Silicon. Weights are separate downloads under their upstream terms; a successful install does not certify a mask or identity.
Human review
Word boundaries can need correction, speaker groups can fragment, visual sampling can miss events and face identity can stay unresolved. Inspect masks through cuts and occlusion before using an effect.
Platform support
The published release will list the exact tested operating systems and minimum tool versions. Native acceleration is qualified on supported hardware, separately from portable core checks.
Recovery & privacy
Project transfer includes source identities and saved corrections. Credentials, browser sessions and executable runtimes stay out of exported projects. A timeout never authorizes a replacement paid job.
