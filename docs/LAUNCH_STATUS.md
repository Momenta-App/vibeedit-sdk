# VibeEdit agent package launch status

**Not launched.** This is an implementation candidate. There is no final qualified archive, final public package version or completed clean-release journey from both Codex and Claude Code. No A01–A20 acceptance criterion is passed.

The delivery scope remains all P0–P10 phases, J1–J7 customer journeys and A01–A20 acceptance criteria. The [public ledger](launch/PUBLIC-LEDGER.json) preserves every requirement and required passing evidence. Each remains open. Original operator state and receipts remain private and unchanged; this page contains a curated status summary.

The package extends the existing public VibeEdit SDK and is installed and operated by the user's agent. It includes portable composition/rendering, creative skills/templates, browser source acquisition, source-bound review/corrections, three paid Myriograph service integrations, optional TransNet/SAM 2.1/SAM 3.1/Apple Silicon MLX model packs, and the Pi companion with BYOK, managed inference and durable goals. These are delivery requirements, not claims that every path is qualified. Existing desktop applications are preserved.

Myriograph remains the account, API, billing, payment and credit authority. The requested commercial model is metered prepaid credit with optional explicitly consented auto top-up. Managed inference and full goal cost/recovery requirements remain mandatory. Local fixtures and existing platform surfaces do not prove new customer signup, sandbox Checkout/email, signed settlement, paid-service calls, worker funding or deployment. Additive database rollout has begun with new policies disabled; no new paid-service or payment journey is established by this evidence.

Bounded local checks cover project/source clocks and revisioned corrections, review UI persistence and rendered changes, original-operation recovery, companion and financial invariants, portable skills and interim archive setup. Model artifacts are pinned, but fresh inference and cut/occlusion/contact mask qualification remain open. Nominal-rate browser frame stepping is approximate for variable-rate sources. Creative revisions and media checks remain subject to principal-workflow user acceptance.

Remaining gates include exact final archives and registry installs, both clean parent-agent journeys, real customer sandbox lifecycle and service settlement, fresh local model inference, BYOK and managed goal execution through crashes/disconnects, meaningful editorial acceptance, platform/update/privacy/retention checks, delivered operational alerts and exercised rollback. The latest full local run passed 266 Python tests with six optional integrations skipped. JavaScript37checks, type checking and package validation pass (445catalog items,44skills,67assets). These source checks do not qualify final release archives or paid/deployed paths.

Owned VibeEdit code uses MIT; optional upstream models/runtimes and OFL fonts retain separate terms. Private research libraries, source movies, model weights, credentials and raw operator screenshots are excluded from the public candidate. Public-source audit and raw receipt identities are hash-bound in the ledger; the final commit identity is intentionally null until release preparation establishes it.
